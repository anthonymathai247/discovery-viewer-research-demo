# Discovery Viewer Research Demo

This repository packages demo materials for Discovery Viewer, a medical AI research platform concept focused on model discovery, dataset discovery, reviewer workflows, and reusable validation studies.

The work is based on public Discovery Viewer pages and product records. It does not claim live clinical deployment, hosted PHI, or completed cross-hospital validation.

## What Is Included

- Investor-style research demo video
- Feature GIFs for model catalog, dataset catalog, and studies/reviewer flow
- Storyboard, timeline, and edit decisions
- Narration script with accuracy notes
- A simple GitHub Pages case-study page

## Product Framing

Discovery Viewer is strongest when framed as a research infrastructure platform:

- Researchers can find models, datasets, and papers in one place.
- Reviewer workflows can make model evaluation more structured.
- Future study records can connect a model, dataset, protocol, result, and reviewer trail.
- Institutions can preserve control over sensitive data while making discovery and access requests clearer.
